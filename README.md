# 詰将棋ボード

詰将棋の学習に個人で使うための、最小機能のWebアプリです。

## 機能

1. **棋譜の貼り付け**: 「クリップボードから貼り付け」ボタンで、詰将棋ノートでコピーした棋譜をそのまま読み込めます。形式は自動判定（SFEN / KIF / CSA / BOD）。クリップボードAPIが使えない環境では「テキストで貼り付け」欄に手動で貼れます。KIFに手順が含まれている場合は初期局面だけを使います。
2. **盤面操作**: 手番側の駒をタップ → 移動・打ち先がハイライト → タップで着手。成れる場合は「成る／成らない」の選択が出ます。「待った」「初期局面に戻す」ボタン付き。
3. **盤反転**: 「反転」ボタンで盤の向き・持駒の上下・座標表示を切り替えます。
4. **詰み探索（詰将棋式）**: Web Worker で探索するので画面は固まりません。攻め方は常に王手、受け方は合法手すべて、打ち歩詰めは反則として除外。最大手数（7/11/15/21/31）と制限時間（5/10/30秒）を選べます。見つかれば「○手詰め」と手順（日本語表記）を表示し、◀ ▶ で盤上を再生できます。「詰みなし」と「時間切れで不明」は区別して表示します。

## 起動方法

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 型チェック + 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果をローカルで確認
npm test         # 自動テスト（vitest）
```

iPadでは、公開したURLを Safari で開き「ホーム画面に追加」するとアプリのように全画面で起動できます（PWA対応）。

## 技術構成

- TypeScript + Vite
- 将棋ライブラリ: [tsshogi](https://github.com/sunfish-shogi/tsshogi)（ShogiHome と同じ作者のライブラリ。棋譜の入出力・合法手判定・打ち歩詰め判定・日本語表記に使用）
- 詰み探索: `src/solver.ts`（反復深化＋置換表＋同一手順内の繰り返し局面打ち切り）。UIからは `src/worker.ts` 経由で呼び出します。

## ファイル構成

```
index.html
public/
  manifest.webmanifest  # PWAマニフェスト
  icon.svg              # アイコン
  sw.js                 # Service Worker（アプリシェルのキャッシュ）
src/
  main.ts      # UI全体（盤描画・タップ操作・反転・再生）
  parse.ts     # 貼り付けテキストの自動判定（SFEN/KIF/CSA）と BOD 自前パーサ
  moves.ts     # 合法手・王手候補の列挙
  solver.ts    # 詰み探索本体
  notation.ts  # 手順の日本語表記変換
  worker.ts    # 探索用 Web Worker
  style.css
tests/
  parse.test.ts   # パースのテスト
  solver.test.ts  # 詰み探索のテスト（1手詰・3手詰・詰みなし）
```

## 既知の制限

- 詰み探索はブラウザ内のJavaScript実装です。目安として、駒数の少ない詰将棋局面で7〜15手程度なら数秒以内に判定できることが多いですが、分岐の多い局面や21手・31手設定では制限時間内に終わらず「時間切れで不明」になることがあります。
- 詰将棋式の探索専用です（王手以外の手から始まる通常の詰み判定はしません）。
- 棋譜の保存・履歴管理・対局・エンジン解析の機能はありません（学習用ボードに絞っています）。
